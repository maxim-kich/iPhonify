# Security

Use GitHub’s private vulnerability reporting to report a security issue. If it is unavailable, open a minimal issue requesting a private contact channel without including sensitive details.

iPhonify uses Accessibility, Screen Recording, and private macOS gesture and window interfaces. Report unintended input suppression, images persisting unexpectedly, or actions affecting unrelated windows.

In-app updates require signed feeds and archives, with verification before extraction. Private signing keys stay outside the repository. Review logs and screenshots before sharing them publicly.
