# iPhonify 0.0.2

- Open Control Center with a two-finger downward swipe from the trackpad’s top-right corner.
- Open the Apple menu with the same gesture from the top-left corner.
- Reduce accidental activation: both fingers must start in the top 3% and the same outer third, then move downward at least 18% of the trackpad height before lifting. Reverse before lifting to cancel.

Both new gestures work on the desktop and in apps while iPhonify is activated. Control Center uses the native Globe–C shortcut. The bottom-edge Home gesture remains available in native fullscreen apps.

Requires an Apple Silicon Mac, macOS 14 or later, and a compatible trackpad.
