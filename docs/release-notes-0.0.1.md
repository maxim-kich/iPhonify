# iPhonify 0.0.1

The first release of iPhonify brings an iPhone-style swipe Home gesture to your Mac.

- Return from a native fullscreen app to the desktop with a two-finger swipe from the trackpad’s bottom edge.
- Set up Accessibility and Screen Recording in the welcome window.
- Control activation from the menu bar or Settings.
- Choose Launch at login and Hide from Dock.
- Check for signed updates in About.

Requires an Apple Silicon Mac, macOS 14 or later, and a compatible trackpad.
